<h1 style="text-align: center" align="center">

`tkbar`

</h1>

A minimalist, hardcoded and secured status bar.

This bar is only meant to be used by me, but of course, you can fork and it and do whatever you want with it. I was personnally unsatisfied with the states of wayland bars and shells (bloat, huge attack surface, not enough config options, not handling some protocols, etc.) so I just wrote a minimal thing that worked for me.

There is no way to "configure" it with any file: everything is hardcoded and it's on purpose. Fork it if you want to change something.
